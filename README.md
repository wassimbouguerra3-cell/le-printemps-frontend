# Le Printemps Superette - Luxury Store Interface

A fully interactive front-end e-commerce interface for "Le Printemps Superette," located in Annaba, Algeria. This project showcases my transition from basic static structures to dynamic, user-focused web development.

# Key Features
- **Interactive UI:** A polished, modern design tailored for a luxury supermarket experience.
- **Dark/Light Mode:** Toggle between themes for enhanced user comfort.
- **Multi-language Support:** Seamless switching between Arabic (AR) and French (FR).
- **Search Functionality:** A built-in search bar for easy product discovery.
- **Responsive Design:** Optimized for a smooth viewing experience across different devices.

# Tech Stack
- **HTML5:** Semantic structure.
- **CSS3:** Styling, layout, and theme customization.
- **JavaScript:** Interactivity, state management, and DOM manipulation.

# Technical Evolution & Lessons Learned
As a developer, I believe in transparency regarding my learning path. This project was a major milestone, but it also highlighted areas for future architectural improvements:

- **Monolithic Architecture:** Currently, the CSS, JS, and HTML are contained within a single file. 
  - *Growth Plan:* I am actively learning to modularize code (splitting into separate CSS/JS files and using component-based structures) for better maintainability.
- **Static Data Management:** Products are currently hardcoded in the script.
  - *Growth Plan:* My next goal is to integrate a backend solution (such as Firebase or Supabase) to enable dynamic product management and a real-time database.
